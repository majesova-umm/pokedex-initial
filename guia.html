    LaboratorioPokédex

    Vas a construir una Pokédex con listado, búsqueda y vista de detalle usando Next.js, React y Tailwind. Marca cada paso como terminado para llevar tu avance.

    • Node.js 20 o superior
    • npm
    • Git
    • VS Code

    Al terminar tendrás el proyecto corriendo en localhost:3000. Tailwind ya está configurado.

    1. Posiciónate en una carpeta limpia para este ejercicio (recuerda los comandos md, cd, etc.).
    2. Clona el repositorio: git clone https://github.com/majesova-umm/pokedex-initial.git
    3. Entra a la carpeta: cd pokedex-initial
    4. Instala los paquetes: npm install
    5. Abre el proyecto en VS Code: code .
    6. Desde la terminal de VS Code ejecuta: npm run dev

    Abre http://localhost:3000. Debes ver el título Pokédex y el mensaje “¡Tu proyecto está listo!”.

    Estos son los archivos con los que vas a trabajar:

    app/ layout.js ← estructura común de todas las páginas page.js ← página principal (aquí empiezas) globals.css ← estilos globales, Tailwind ya configurado

    En Next.js cada carpeta dentro de app/ es una ruta, y su archivo page.js es lo que se muestra en esa ruta.

    Compilas la versión de producción y la ejecutas.

    2. Ejecuta npm run build. Al terminar verás un resumen de las rutas:

    La página principal es estática (○): el servidor la entrega igual a todos y el navegador descarga los Pokémon. El detalle es dinámico (ƒ): el servidor la genera en cada visita, porque depende del id de la URL. El resultado de la compilación queda en la carpeta .next.
